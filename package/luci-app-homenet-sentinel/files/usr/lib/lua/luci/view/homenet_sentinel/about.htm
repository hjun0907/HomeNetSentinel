<%:HomeNet Sentinel（家庭网络哨兵）%>

<%:在 OpenWrt 路由器上运行的家庭网络监控服务：通过 ARP/NUD 主动探测判断家庭成员设备的在家/离家状态，并监控广域网链路速率、流量、连接数与 IPv4/IPv6 地址，数据经 MQTT 上报，并自动注册为 Home Assistant 实体。%>

<%:版本信息%>

<%:软件版本：%><%=ver%>

<%:主要功能%>

  • <%:在家检测：%><%:主动 ARP 探测 + 防抖判定，设备在线/离家约 15 秒内更新。%>
  • <%:HA 自动发现：%><%:每个目标注册为 binary_sensor 在线状态传感器，WAN 指标注册为传感器。%>
  • <%:WAN 监控：%><%:上/下行速率、累计流量、连接数、IPv4 地址、IPv6-PD 前缀。%>
  • <%:在线状态页：%><%:实时显示设备名称、MAC、IP、无线信号强度与在线状态。%>

<%:配置说明%>

<%:在“基础设置”标签中填写 MQTT 服务器信息并启用服务；在“在家检测目标”中添加要监控的设备名称与 IP 地址。%>

<%:设备在线状态通过路由器邻居表（ip neigh）判定，无线信号强度来自 iwinfo（仅关联到本路由器无线的设备可显示）。%>
